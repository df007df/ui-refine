# 设计判断与精修

在要调整构图、中文排版、视觉语言、动效或关键状态时读取。先识别页面主任务，再决定表现强度。

## 任务决定表达

| 页面主任务 | 优化重点 | 代表性检查 |
| --- | --- | --- |
| 决定是否了解/购买 | 真实价值、可信证据、主动作、品牌记忆点 | 首屏知道产品和下一步；长页节奏；价格/权益事实一致 |
| 完成高频操作 | 对象、当前状态、判断依据、操作反馈、密度 | 实际列表/表单/编辑器；保存、失败恢复、重复操作 |
| 阅读和理解 | 中文行长、层级、混排、目录和查找 | 长文、代码/表格、字体放大、窄屏阅读 |
| 体验作品或内容 | 内容主体、节奏、适度情绪表达 | 内容可见；进入/退出和减少动态效果仍可用 |

一个产品可以有不同任务页面。已有品牌、布局和组件可有效完成任务时直接深化；明确要求整体改版时才探索新的视觉身份。营销风格的 hero、巨型标题与低密度卡片按任务选用。

## 新方向与参考图

从产品品类、用户首屏任务、现有品牌及有依据的参考形成方向。方向卡只需：主角/主动作、信息组织、字体/密度/配色、记忆点、与任务的关系。方案数量随请求定；只换颜色的同一骨架不能作为有意义的方案比较。

小样使用同一真实内容、数据状态和目标尺寸。比较后记录选择与修改理由；已确定方向直接实施。新品牌方向的关键缺口才集中提问，不能把小改动扩大成设计访谈。

还原截图时先确定图像尺寸、视口、缩放、资源与可滚动区域。拆出区域比例、对齐、文字层级、裁切与固定/流动关系，再转为目标框架中可编辑的控件。图片稿只能证明外观意图，不能证明交互或原生 App 已实现。

## 视觉检查

- **层级**：页面的对象、当前状态和主动作先被认出。通过尺寸、位置、对比、留白表达主次，保留判断依据；删除重复装饰和赘述后重新检查理解。
- **中文排版**：在实际字号看多行标题、正文、按钮和中英混排。调整容器、行高和信息分组来处理换行；窄屏以重排和渐进披露承载信息。使用项目可用字体及回退，不缩小整页掩盖溢出。
- **空间/密度**：沿用 token 建立组内和组间节奏；后台看真实行列、筛选及横向比较，长文看阅读节奏。密度本身不是缺陷，分组和对齐是否支持任务才是依据。
- **颜色/主题**：建立文字、背景、边界、强调、成功、警告、错误的语义角色。复用已定义的变量或目标平台角色，分别检查浅/深主题与可读对比。信息除颜色外有名称、形状或图标含义。
- **组件/图标**：相同职责采用相同语法；同套图标的大小、笔画和对齐一致。图标独立承担动作时有可访问名称，必要时保留可见文字。
- **素材**：资产承担信息、内容识别或品牌表达时才使用。先复用真实产品素材；需要生成时使用已授权、可用的工具，并在交付记录说明。价格、评价、成果、计数从真实数据取值。

## 状态与文案

从真实任务列出受影响状态，不要求每个项目增加所有状态。表单/列表/弹层重点检查：

| 状态 | 界面应回答 | 行为要点 |
| --- | --- | --- |
| 首次读取/加载 | 正在取什么，何时可操作 | 迟到的读取不能覆盖新输入；有明确可操作边界 |
| 空内容/无筛选结果 | 是真的没有，还是当前筛选不可见 | 保留筛选和恢复入口，使用实际含义 |
| 错误/保存失败 | 哪一步失败，如何继续 | 保留输入/位置；重试当前有效内容；不误报成功 |
| 保存中/成功 | 哪个版本已确认 | 防重复提交；编辑后撤销过期成功提示；旧响应不确认新内容 |
| 禁用/权限不足 | 为什么不能做，如何满足条件 | 使用业务真实条件；不靠淡色隐藏原因 |
| 长标题/长表格/大字 | 内容和动作是否仍可理解 | 对象与状态保留；适当换行、滚动或详情入口 |

文案描述对象、动作和结果，错误指向可恢复的下一步。`0`、空字符串、`null` 和业务“未设置”分别按契约展示，不用一个真假判断吞掉有效数据。业务 enum 的标签和存储值以当前契约为准。

## 动效

用动效解释操作反馈、对象变化或层级关系。按受影响交互设计，不为每个小改动新增动画；高频操作允许快速响应，中断后可继续。触控手势保持跟手与目标平台返回习惯，桌面保留键盘路径。

优先使用当前框架/组件的合适实现，检查实际动画、主线程和资源开销。系统减少动态效果开启时提供较少运动的等价反馈。静态截图只能检查静态画面；声称动效完成时查看实际播放或录屏。

## 一个完整应用例：中文设置页

输入：现有绿色品牌、工作区名称/状态/备注、今日记录数为 0、保存成功反馈，手机宽度下有横向溢出。

判断：任务是编辑并保存设置。沿用绿色作为主操作强调，采用清晰的表单分组和单列窄屏布局，最近记录保留可比较列。读取原状态值及本地保存逻辑；从共享样式修复宽度、行高和焦点。

实施：保留“未设置”的 `null` 和数字 0；按钮、字段标签、成功/失败反馈保持语义；内容随容器变化，表格宽度不足时在自身区域处理。

验收：查看桌面/窄屏和键盘焦点；编辑后保存，再加载核对三个字段和状态值；故意制造写入失败，确认内容仍在且提示可见。交付实际检查结果及截图位置；没有执行的项目单独列出。
