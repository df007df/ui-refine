# Chrome 扩展 UI

从 manifest、entrypoint 和请求确认载体，继续项目现有 WXT/Plasmo/原生扩展等栈。普通网页走 [Web](web.md)。

## 载体决定布局和生命周期

| 载体 | 美化与行为重点 | 验收重点 |
| --- | --- | --- |
| popup | 快速呈现主动作；空间紧凑；恢复必要草稿/状态 | 从工具栏打开、外部点击关闭、重新打开、实际加载/权限/失败 |
| options | 设置分组、依赖与保存反馈；窄宽度重排 | 保存后重读、跨上下文生效、无效输入、重载后的值 |
| side panel | 窄且可调整的任务区域；当前 tab 与草稿的关系明确 | 调宽、切 tab、关闭重开、扩展重载、需要时浏览器重启 |
| content UI | 局部操作不遮挡宿主主任务；样式、位置和事件边界 | 宿主样式/滚动/SPA 路由、重复注入、卸载、焦点与遮挡 |

popup 在浏览器其他位置获得焦点时关闭；长任务可在已有 side panel/options 等合适入口延续，不能依靠强制保持 popup 打开。脚本使用扩展打包产物。见 [Chrome popup 官方说明](https://developer.chrome.com/docs/extensions/develop/ui/add-popup)。

## 草稿与保存真值

从产品需求确定：全局或按 tab/对象的草稿；关闭 UI、扩展重载、浏览器重启、跨设备分别需要保留什么。按需求选择存储，不根据函数名或示例描述假定持久性。

| 存储 | 适用条件 |
| --- | --- |
| `storage.session` | 扩展加载期间的内存状态；重载、更新、禁用或浏览器重启会清除 |
| `storage.local` | 需要跨浏览器重启保持的本地草稿/较大状态；扩展移除时清除 |
| `storage.sync` | 有跨设备同步需求且满足容量/频率约束的较小设置；按产品隐私与数据规则选择 |

这些生命周期依据 [Chrome storage 官方说明](https://developer.chrome.com/docs/extensions/reference/api/storage)；使用项目 API 的包装形式时检查对应 storage area。WXT 的 `session:`/`local:` 等前缀必须与需求一致，参考片段中的“持久化”注释不能替代底层语义。

最少区分首次恢复、编辑版本、正在写入、已确认版本与失败。读取未完成前禁用相关编辑，或用明确策略保护已发生的编辑；读取失败提供恢复入口。只有对应写入成功才显示已保存，编辑后撤销过期确认；旧响应不能把新内容误标成功。

需要关闭前保留未手动保存的编辑时，明确自动恢复快照与手动保存的含义；确保可恢复快照进入合适的存储/消息路径。不能只依赖即将销毁的 UI 定时器或退出事件。需要后台协调时沿现有架构实现，确认发送/写入完成及顺序；读写权限、配额和消息失败都要能保留当前输入并重试。仅“成功保存过的草稿需恢复”时不扩大为新的自动保存系统。

改变 schema/storage area 时检查已有数据，按项目约定迁移；本地已有值不能被旧或空值覆盖。多个上下文共享状态时使用适合的变更通知，避免切 tab 被动覆盖正在编辑的草稿。

## 注入、CSP 与性能

content UI 采用当前项目的 Shadow DOM/iframe/作用域策略。根据实际宿主处理继承、CSS 变量、层级和字体；隔离方案不能仅凭名称证明无冲突。SPA/扩展更新后清理 UI、监听器和观察者；初始化可重复但不重复挂载。

生产 MV3 的 extension pages 使用其实际 CSP 和打包资源；单文件原型里的内联脚本、远程代码或 `eval` 不能直接搬进生产扩展。sandbox pages 是另一个策略与权限边界，按项目配置单独处理。见 [Chrome CSP 官方说明](https://developer.chrome.com/docs/extensions/reference/manifest/content-security-policy)。

沿已有入口拆分资源，popup 的首屏不等待无关重包；字体、图标、动画按任务需求选择。修复实测打开/交互瓶颈，不为美化扩大 manifest 权限。service worker 的运行生命周期和 UI 生命周期分别检查，不能用模块全局变量作为跨生命周期的保存真源。

## 验证

样式页在 localhost 的预览可用于布局，平台结论来自已加载的扩展。按载体执行表中动作；涉及保存时检查最后确认的内容和重读结果，涉及未保存恢复时也测试关闭前最新编辑。模拟读/写/消息失败，确认错误可见、输入仍在和重试有效。
